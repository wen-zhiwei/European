# 一起去欧洲：微信小程序样板课

这是从已确认的网页样板课转换出的**原生微信小程序工程**。可以直接导入微信开发者工具，不是普通网页套壳。

## 已完成

- 首页 → 认识欧洲 → 英语练习 → 完成页。
- 欧洲概览、东西南北欧、44 国分区、6 个延伸国家和 1 个争议地区。
- NASA Blue Marble 现成地图素材；没有使用 AI 生图或视频。
- 微信小程序本地缓存保存学习进度；漏学不跳课，重看不撤销完成状态。
- 使用小程序录音 API，支持录音、停止和当前页面回放，最长 30 秒。
- 保持大字、大图、大按钮；详细分区解释放在按需打开的弹层里。

## 导入微信开发者工具

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择克隆后的仓库根目录。
4. 使用与你的小程序账号对应的 AppID，并用管理员或开发者微信登录开发者工具。
5. 编译成功后，可使用“预览”进行手机测试，或上传为开发版本。

## 主要文件

- `miniprogram/pages/index/index.wxml`：页面结构。
- `miniprogram/pages/index/index.wxss`：适老化大字、大按钮样式。
- `miniprogram/pages/index/index.js`：学习、地图和录音交互。
- `miniprogram/utils/progress.js`：可测试的学习进度逻辑。
- `miniprogram/utils/europe-data.js`：欧洲分区与 51 个国家/地区数据。
- `miniprogram/utils/geography.js`：地图裁切和点位计算。

地图素材来源与 SHA-256 保存在 `miniprogram/assets/source.json`。地图点位仅用于大致定位，不表示国界或国土中心。
